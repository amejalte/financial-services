# WORKLOG — 로컬 작업 지시서

로컬 Claude Code에 "작업 N-M 진행해줘"라고 넘기면 되는 단위로 쪼갰습니다.
각 작업은 **완료 조건**이 있고, 끝나면 아래 체크박스를 채우고 한 줄 메모를 남깁니다.
설계 근거는 전부 DESIGN.md에 있으니, 작업 중 판단이 필요하면 해당 절을 먼저 읽습니다.

규칙
- 비밀값(앱키, 토큰, 계좌번호)은 `.env`에만 두고 `.gitignore`에 추가. 커밋 전 `git diff`로 확인.
- 한 작업이 끝날 때마다 커밋. 메시지 예: `feat(expiry-alert): 작업 1-2 텔레그램 발송 함수`
- 모르는 규정·API 사양은 추측하지 말고 DESIGN.md 8장 확인 항목에 적고 사용자에게 질문.
- 저장소 루트의 `python3 scripts/check.py`는 이 폴더와 무관하지만, 커밋 전 한 번 돌려 깨지지 않는지 확인.
