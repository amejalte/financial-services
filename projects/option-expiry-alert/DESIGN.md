# DESIGN — 옵션 만기 알림 시스템 설계서

작성일: 2026-11-08 · 대상 독자: 비개발자(투자자) + 로컬 Claude Code

이 문서는 "무엇을, 언제, 어떤 규칙으로" 알릴지를 정합니다. 코드 구조는 WORKLOG.md에서
작업 단위로 다룹니다. 끝의 8장 **확인 필요 항목**은 구현 전에 반드시 검증합니다.

## 1. 용어 (한 줄 정리)

| 용어 | 뜻 | 왜 보는가 |
|---|---|---|
| 최종거래일 | 선물·옵션을 마지막으로 거래할 수 있는 날. 이 날 15:20까지만 거래 | 알림 기준일(D-0) |
| 동시만기 | 3·6·9·12월 둘째 목요일. 선물·옵션·주식선물·주식옵션이 한꺼번에 만기 | 수급 규모가 평달의 수 배 |
| 종가 단일가 | 15:20~15:30 주문을 모아 한 번에 체결. 옵션은 이 코스피200 종가로 현금 정산 | 만기 충격이 터지는 10분 |
| 미결제약정(OI) | 아직 청산되지 않은 계약 수. 행사가별 콜/풋 OI 분포를 봄 | 종가가 "끌려갈" 가격대 추정 |
| 맥스페인 | 옵션 매수자의 손실 합이 최대(=매도자에게 가장 유리)가 되는 지수대 | 종가 수렴 후보 중 하나 |
| 베이시스 | 선물가격 − 현물지수. 양수면 콘탱고, 음수면 백워데이션 | 차익 프로그램 매매 방향 결정 |
| 차익 프로그램 | 현물 바스켓과 선물을 반대로 들고 베이시스 차익을 노리는 매매. 만기일에 현물 쪽을 한꺼번에 청산 | 만기 매물/매수의 핵심 |
| 차익잔고 | 아직 청산 안 된 차익 프로그램 현물 보유액(매수차익/매도차익) | 만기일 잠재 매물 크기 |
| 롤오버 | 근월물을 청산하고 차월물로 옮기는 것 | 롤오버가 많으면 만기 충격 작음 |
| 스프레드 거래 | 근월·차월 동시 매매(롤오버 수단). 거래량으로 롤오버 진행률 추정 | 위와 같음 |
| 풋콜비율(PCR) | 풋 ÷ 콜 (거래량 또는 OI) | 시장의 방어 심리 |
| 위클리 옵션 | 매주 월·목 만기인 단기 옵션. 선물은 만기 아님 | 월물보다 가벼운 알림 대상 |

## 2. 일정 로직

### 2.1 월물 만기

- 기준: **매월 둘째 목요일**. 휴장일이면 **직전 거래일로 앞당김**.
- 동시만기: 3·6·9·12월.
- 알림 날짜 (모두 거래일 기준으로 보정):

| 코드 | 날짜 | 알림 시각 | 성격 |
|---|---|---|---|
| D-6 | 전주 금요일 | 18:30 (장 마감 데이터 확정 후) | 사전 브리핑: 누적 포지션 출발점 |
| D-3 | 월요일 | 18:30 | 일일 현황 |
| D-2 | 화요일 | 18:30 | 일일 현황 |
| D-1 | 수요일 | 18:30 | 일일 현황 + 만기 전날 종합 관점 |
| D-0 | 목요일 ① | 08:30 | 개장 전 최종 포지션, 당일 체크리스트 |
| D-0 | 목요일 ② | 14:30 | 리마인드: 14:50 프로그램 사전신고, 15:20 종가 단일가 시작 |
| D-0 | 목요일 ③ | 16:00 | 결과: 종가, 접속매매 마지막가 대비 차이, 프로그램 순매수 |

  (`scripts/expiry_calendar.py` 출력 참고).
- 12월 동시만기는 **배당**(12월 결산 배당락 전) 때문에 베이시스가 평소와 다르게 움직임 → 4.4절 특례.

### 2.2 위클리 옵션

- 매주 **월요일물·목요일물**. 목요일물은 **월물 만기주에는 상장되지 않음**(월물 만기로 대체).
- 알림은 2회로 제한:
  - 전일 18:30: 콜/풋 OI 집중 행사가 3개, PCR, 현재 지수와의 거리
  - 당일 14:30: 15:20 거래 종료 리마인드 + OI 집중가 재확인
- 위클리는 "관점"을 내지 않고 **위치 정보만** 보냄(해석 규칙 적용 안 함). 포지션 보유 시에만 켜는 옵션 플래그 `WEEKLY_ALERTS=on/off`.

### 2.3 겹치는 일정 체크 (D-6 브리핑에 포함)

| 일정 | 시점 | 왜 겹치면 중요한가 |

| 코스피200 정기변경 | 6월·12월 동시만기일 **다음 거래일 적용** → 동시만기일 종가에 편입·제외 종목 리밸런싱 | 종가 단일가에 패시브 자금 수급 추가 |

## 4. 해석 규칙 (수급 → 관점)

관점은 **상방 / 하방 / 중립(핀)** 셋 중 하나와 **강도(약·중·강)**. 아래 신호를 점수화해 합산합니다.
점수는 출발값이며 5단계 리뷰 루프에서 조정합니다.

### 4.1 신호표

| # | 신호 | 조건 (만기주 누적 기준) | 점수 | 해석 |
|---|---|---|---|---|
| S1 | 외국인 선물 누적 순매수 | +5,000계약 이상 | +2 | 상방 압력, 만기 전 환매 가능성도 체크 |
| S1' | 외국인 선물 누적 순매도 | −5,000계약 이하 | −2 | 하방 압력 |
| S2 | 베이시스 | 콘탱고 확대(괴리율 +0.3% 이상) 지속 | +1 | 매수차익 잔고 쌓임 → 만기일 **매도** 전환 위험 (−1로 반전 가능, 4.3절) |
| S2' | 베이시스 | 백워데이션(괴리율 −0.3% 이하) 지속 | −1 | 매도차익 잔고 → 만기일 **매수** 환매 가능 (+1 반전 가능) |
| S3 | 매수차익잔고 | 만기주 들어 증가 | −1 | 만기일 종가 매물 후보 |
| S3' | 매도차익잔고 | 만기주 들어 증가 | +1 | 만기일 종가 매수 후보 |
| S4 | 콜 OI 집중가 | 현재 지수 위 1~2 행사가에 집중 | 0 / 천장 표시 | 상단 저항(핀 후보) |
| S4' | 풋 OI 집중가 | 현재 지수 아래 1~2 행사가에 집중 | 0 / 바닥 표시 | 하단 지지(핀 후보) |
| S5 | 맥스페인 vs 현재 지수 | 차이 1% 이상 | 맥스페인 방향 ±1 | 매도자 유리 방향으로 수렴 가능성 |
| S6 | 롤오버 진행률 | 스프레드 거래량이 전월 대비 높음(D-1 기준) | 강도 −1단계 | 충격 완화 |
| S7 | 외국인 현물 누적 | 선물 방향과 **같음** | 강도 +1단계 | 방향 신뢰도 상승 |
| S7' | 외국인 현물 누적 | 선물 방향과 **반대** | 강도 −1단계 | 헤지성 포지션 가능, 관점 약화 |
| S8 | PCR(OI) | 1.3 이상 | +0.5 | 과도한 방어 → 숏커버 여지 |
| S8' | PCR(OI) | 0.7 이하 | −0.5 | 낙관 과열 |

합산: **+2 이상 상방, −2 이하 하방, 그 사이 중립(핀)**. 강도는 |합산| 2→약, 3→중, 4 이상→강, 여기에 S6·S7 보정.

### 4.2 맥스페인 계산

행사가 K마다 "지수가 K에서 끝났을 때 모든 콜·풋 매수자의 내재가치 합"을 계산하고, 합이 가장 작은 K가 맥스페인.
내재가치 합 = Σ 콜OI(k)·max(K−k,0) + Σ 풋OI(k)·max(k−K,0). 행사가 간격은 2.5pt.

### 4.3 만기일 전환 규칙 (D-1 → D-0 관점 뒤집기)

만기주에 쌓인 차익 포지션은 만기일에 **반대로 청산**됩니다. 그래서 D-1까지의 방향 신호와 D-0 종가 충격은 다를 수 있습니다.

- 매수차익잔고가 크고 베이시스가 만기일 오전에 축소/백워데이션 → D-0 알림에 "**종가 매도 출회 가능**" 경고.
- 매도차익잔고가 크고 베이시스가 확대 → "**종가 매수 환매 가능**".
- 롤오버가 충분(S6)하면 위 경고의 강도 한 단계 낮춤.
- 14:30 알림에서 **당일 베이시스 추이 + 14:50 프로그램 사전신고 규모**(공시되면)를 최종 근거로 씀.

### 4.4 특례

- **12월 동시만기**: 배당 수취 목적의 매수차익 보유는 만기일에 청산되지 않는 경우가 많음 → S3 점수를 절반으로. 이론 베이시스 계산에 배당지수 반영.
- **동시만기 전체**: 주식선물·옵션 만기가 겹쳐 종가 단일가 수급 규모가 큼 → 강도 한 단계 상향, 알림 제목에 `[동시만기]` 표시.
- **정기변경·리뷰 겹침**: 2.3절 일정이 같은 날이면 "종가 쏠림은 수급 해석과 무관할 수 있음" 주의 문구 자동 삽입.

### 4.5 알림 문장 구조 (해석 엔진 출력)

```
관점: 하방 (중)
근거:
 1. 외국인 선물 만기주 누적 −7,800계약 (S1')
 2. 매수차익잔고 +3,200억 증가, 콘탱고 지속 → 만기일 매도 전환 위험 (S2, S3)
 3. 풋 OI 집중 537.5 / 콜 OI 집중 545.0, 맥스페인 540.0 (현재 542.1)
주의: 롤오버 스프레드 거래량 전월 대비 1.4배 → 충격은 제한적일 수 있음 (S6)
반대 시나리오: 외국인 현물은 +4,100억 순매수 — 선물 매도가 헤지라면 종가 하락 폭 작음 (S7')
```

규칙: 근거 3줄, 주의 1줄, 반대 시나리오 1줄을 **항상** 포함. 숫자 없는 근거는 쓰지 않음.

## 6. 운영 흐름

```
18:00  수집 실행 (KIS → 실패 시 보조 소스 → 그래도 실패면 "데이터 미수신" 알림)
18:10  CSV 저장, 누적 계산
18:20  해석 엔진 실행 (월물 만기주에만)
18:30  텔레그램 발송, alerts/ 에 본문 저장
```

- 실행 주체: GitHub Actions 스케줄(권장) 또는 PC 작업 스케줄러. 둘 다 `python main.py --date 2026-12-08 --slot evening` 형태로 호출.
- 비밀값(KIS 앱키·시크릿·계좌, 텔레그램 봇 토큰·chat_id)은 GitHub Secrets 또는 로컬 `.env`에만. 저장소에 절대 커밋하지 않음.
- 실패 처리: 어떤 항목이든 못 받으면 그 칸을 `n/a`로 두고 알림은 보냄. 핵심 항목(외국인 선물, 베이시스) 둘 다 없으면 관점 계산 생략.

## 7. 데이터 소스 대체 전략

| 순위 | 소스 | 장점 | 단점 | 사용 조건 |
|---|---|---|---|---|
| 1 | KIS Developers API | 무료, 안정, 휴장일 조회 | 선물옵션 투자자별 항목 제공 범위 미확인 | 기본 |
| 2 | KRX 정보데이터시스템 (data.krx.co.kr) | 모든 공식 통계, 차익잔고 유일 소스 | 비공식 호출, 화면 개편 시 깨짐 | 차익잔고 + KIS 미제공 항목 |
| 3 | 네이버 금융 선물옵션 페이지 | 간단 | 수치 정밀도·지연 | 긴급 대체 |
| 4 | 수동 입력 (`manual/YYYY-MM-DD.csv`) | 항상 가능 | 손이 감 | 리허설, 장애 시 |

1단계 리허설(2026-11-12 만기)은 4번 수동 입력으로 알림 뼈대만 검증.
