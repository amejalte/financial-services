# 옵션 만기 알림 시스템 (Option Expiry Alert)

코스피200 선물·옵션 만기일을 **수급 관점**으로 미리 읽고, 전주 금요일부터 만기 목요일까지
포지션 변화를 텔레그램으로 받아보는 개인용 시스템입니다.

이 폴더는 "설계 → 로컬 구현" 순서로 작업하기 위한 문서 묶음입니다. 코드는 아직 없고,
만기 캘린더 산출 스크립트 하나만 들어 있습니다.

## 문서 구성

| 파일 | 역할 | 읽는 순서 |
|---|---|---|
| `PLAN.md` | 목표, 범위, 단계별 로드맵, 결정 사항 | 1 |
| `DESIGN.md` | 데이터 항목 정의, 해석 규칙, 알림 템플릿, 일정 로직, 미확인 항목 | 2 |
| `WORKLOG.md` | 로컬 Claude Code에 그대로 넘길 수 있는 작업 지시서(체크리스트) | 3 |
| `scripts/expiry_calendar.py` | 만기일·알림일 산출 (휴장일 앞당김, 동시만기, 위클리 포함) | 참고 |

## 로컬에서 시작하는 법 (비개발자 기준)

1. 이 저장소를 내 PC에 내려받고(또는 이미 있으면 `git pull`) 이 폴더로 이동합니다.
2. 터미널에서 Claude Code를 열고 다음처럼 요청합니다.

   ```
   projects/option-expiry-alert/WORKLOG.md 의 "작업 1-1"부터 순서대로 진행해줘.
   진행 전에 DESIGN.md 를 먼저 읽고, 확인 필요 항목은 나에게 물어봐.
   ```

3. 캘린더만 바로 보고 싶으면:

   ```
   python3 scripts/expiry_calendar.py          # 2026~2027 월물 + 향후 8주 위클리
   python3 scripts/expiry_calendar.py --weekly # 위클리만
   ```

## 확정된 결정 (2026-11-08)

- 수급 데이터 기본 소스: **한국투자증권 KIS Developers API** (보조: KRX 정보데이터시스템, 네이버 금융)
- 알림 채널: **텔레그램만** (기록은 로컬 마크다운/CSV 파일)
- 1차 범위: **월물 만기 + 위클리 옵션(월·목)**
- 문서 수준: 한국어, 비개발자 기준 (로직·규칙 중심)

## 주의

- 이 시스템은 **정보 알림**용입니다. 자동 주문 기능은 설계 범위 밖이며 넣지 않습니다.
- 만기일·휴장일은 스크립트가 계산하지만, 운영 전 반드시 KRX 공지로 교차 확인합니다.
