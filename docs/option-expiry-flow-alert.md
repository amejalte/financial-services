# KOSPI200 옵션 만기 수급 알림 — 설계 문서

> 작성일: 2026-11-09 · 상태: 설계 완료, 데이터 통로 미확정 (프로젝트 보관용 정리본)

## 1. 목표

KOSPI200 옵션 만기 직전 5거래일 동안 주요 투자자의 파생 수급을 매일 정리해서, 텔레그램에 바로 공유할 수 있는 짧은 요약으로 받아보는 것.

- **추적 기간**: 만기 전주 금요일 ~ 만기주 목요일 (5거래일)
- **결과물**: 텔레그램 공유용 짧은 요약 (숫자는 정확히, 설명은 비유·밈 섞어 쉽게)

## 2. 만기 일정 규칙

- 매월 **둘째 목요일**이 옵션 만기일
- **3·6·9·12월**은 주가지수 선물·옵션·개별주식 선물·옵션이 함께 끝나는 **동시만기** (변동성 주의)
- 만기일이 휴장일이면 직전 거래일로 앞당겨짐 → KRX 휴장일 확인 필요
- 매일 요약에 **다음 만기까지 D-day** 표시

| 만기일 | 추적 시작(전주 금) | 비고 |
|---|---|---|
| 2026-11-12 (목) | 2026-11-06 | 월물 만기 |
| 2026-12-10 (목) | 2026-12-04 | **동시만기** |
| 2027-01-14 (목) | 2027-01-08 | 월물 만기 |
| 2027-02-11 (목) | 2027-02-05 | 월물 만기 (설 연휴 확인) |
| 2027-03-11 (목) | 2027-03-05 | **동시만기** |

## 3. 추적 항목

| 구분 | 외국인 | 금융투자 | 개인 |
|---|---|---|---|
| KOSPI200 선물 순매수 (계약) | ✔ | ✔ | ✔ |
| 콜옵션 순매수 (계약) | ✔ | ✔ | ✔ |
| 풋옵션 순매수 (계약) | ✔ | ✔ | ✔ |

- 각 항목의 **당일 값 + 5일 누적 합계**
- **차익거래 잔고**: 전일 대비 증감 (만기일 현물 매물 출회 가능성 판단용)
- **D-day**: 다음 만기까지 남은 거래일

## 4. 해석 포인트 (예시)

| 수급 패턴 | 쉬운 해석 |
|---|---|
| 외국인 선물 매수 + 콜 매도 + 풋 매수 | "오를 것 같긴 한데 보험은 들어둔" 포지션. 방향은 위, 확신은 반쯤 |
| 금융투자 선물 매도 (대량) | 현물 사고 선물 파는 차익거래 가능성 → 만기일에 현물이 한꺼번에 나올 수 있음 → **차익잔고 증가 여부 확인** |
| 차익잔고 크게 쌓인 채 만기 접근 | 만기일 장 마감 동시호가에 프로그램 매도 출회 주의 |
| 개인 콜 대량 매수 | 복권 사는 심리. 반대 방향 신호로 참고만 |

> 해석은 참고용이며 투자 판단은 본인 책임.

## 6. 데이터 소스 비교 (2026-11-09 조사)

| 소스 | 선물·옵션 투자자별 수급 | 차익잔고 | 비용·조건 | 판단 |
|---|---|---|---|---|
| 메리츠 Open API (2026-10 출시, REST) | ✘ (주식 중심) | ✘ | 무료, 계좌 필요 | **부적합** |
| KRX 정보데이터시스템 | ✔ | ✔ | 무료, 계좌 불필요 | **하루 1회용 1순위** |
| 키움 REST API | ✔ (선물옵션 지원) | 확인 필요 | 무료, 키움 계좌 필요 | **장중 실시간용 1순위** |
| 한국투자증권 KIS API | 시세 ✔, 수급 범위 추가 확인 필요 | 확인 필요 | 무료, 한투 계좌 필요 | 보조 후보 |

현재 PC 환경: `krx-stock-price` 도구만 있음 (주식 시세 전용, 파생 수급 불가). KIS 연결 안 됨.

## 7. 미결 사항

1. **하루 1회 vs 장중 실시간** — 하루 1회면 KRX만으로 충분, 실시간이면 키움 계좌·API 신청 필요
2. **데이터 통로 확정** — KRX 화면 자동 조회 / 키움 REST / KIS 중 선택
3. **발송 채널** — 텔레그램 봇 직접 발송 vs 요약만 받아서 수동 공유

## 8. 이어서 작업하는 법 (단계별)

1. **방식 고르기**: 처음엔 "하루 1회(장 마감 후)"로 시작 추천. 계좌·API 신청 없이 바로 가능.
2. **데이터 확인**: KRX 정보데이터시스템(data.krx.co.kr) → 파생상품 → 투자자별 거래실적에서 선물/콜/풋 수치가 나오는지, 통계 → 프로그램매매 → 차익거래잔고 화면을 확인.
3. **Claude에게 요청**: 이 문서를 첨부하고 "8단계 2번 데이터로 오늘 요약 만들어줘"라고 요청.
4. **자동화**: 잘 되면 "만기 주간 평일 장 마감 후 매일 실행" 루틴으로 등록 (이전에 평일 16:40 KST 루틴을 만든 적 있음).
5. **텔레그램 연결**: 텔레그램 봇 토큰을 만들어 자동 발송까지 연결 (선택).
6. **실시간이 필요해지면**: 키움 계좌 개설 → 키움 REST API 신청 → 앱키 발급 후 Claude에게 연결 요청.
